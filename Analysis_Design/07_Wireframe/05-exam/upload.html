"answers.jpg" không phải file PDF. Hãy xuất đáp án ra PDF.

Quy định file (đọc trước khi tải)
  • PDF nên có lớp chữ (không phải ảnh scan), tối đa 20 MB mỗi file.
  • Audio MP3 hoặc M4A, một file cho cả bài, tối đa 60 MB.
  • File đáp án đánh số câu rõ ràng. Nhiều cách viết thì ngăn bằng / hoặc OR; phần tùy chọn để trong ngoặc, ví dụ (the) library.
  • Đề Full: một PDF gồm cả Listening và Reading; hệ thống tự chia đáp án.
  • Chỉ tải đề bạn có quyền dùng. Đề riêng tư cho tới khi bạn đăng lên thư viện.
Tải bộ file mẫu
