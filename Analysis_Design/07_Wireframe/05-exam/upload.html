2. File

Đề có đáp án hoặc giải thích ở cuối thì chọn cùng một file cho nhiều ô. Hệ thống tự lấy đúng phần cho từng ô.

Quy định file (đọc trước khi tải)
  • PDF nên có lớp chữ, tối đa 20 MB mỗi file.
  • Audio MP3 hoặc M4A, một file cho cả bài, tối đa 60 MB.
  • Đáp án đánh số câu rõ ràng. Nhiều cách viết thì ngăn bằng / hoặc OR; phần tùy chọn để trong ngoặc, ví dụ (the) library.
  • Chỉ tải đề bạn có quyền dùng.

Thường mất 1–3 phút. Bạn có thể rời trang trong lúc chờ.
